The first link is tied directly with my resume, so if anyone clicks it they should be able to see it in a new tab. 
The second link is my portfolio, which just has to be updated. I have a template working from a class, however, some of the information it has is not complete and isn't indicative of my actual projects.
The third link is my LinkedIn profile, so whoever clicks it can choose to message me, connect, or simply check my profile out if they want to.
The last and fourth link is for my GitHub page. It shows off some projects that I had pinned previously as well as the simple profile overview.

To run the website locally, the command "npm run dev" should be used. Otherwise, it should be running properly on GitHub Pages. You can contact me via email at diegoacosta006@gmail.com if there is a problem.

My JS feature is a simple time-of-day greeting. When someone accesses my Linktree, they will be greeted differently based on the time. Anything before 12:00pm is considered morning. From 12:00pm up until 6:00pm is considered afternoon. Anything past this time is simply evening. I decided to go with this feature because I think that a nice greeting message can be impactful and leave a nice impression on the user.
